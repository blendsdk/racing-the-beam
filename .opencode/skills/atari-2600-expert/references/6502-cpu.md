# The 6502 / 6507 CPU — Reference

The Atari 2600 uses a **MOS 6507**: an NMOS 6502 CPU in a smaller 28-pin package.
Instruction set, registers, and timing are identical to the 6502. The differences that
matter for this course:

| 6507 trait | Consequence |
| --- | --- |
| Only 13 address lines (A0–A12) | 8K address space; all accesses mirror every 8K. The cartridge is 4K at `$F000–$FFFF`. |
| No IRQ or NMI pins | The `$FFFA/$FFFE` vectors are ignored; interrupts are never generated. The reset vector at `$FFFC` is the only one that matters. |
| Clocked at 1/3 of the color clock | NTSC ≈ 1.19 MHz, PAL ≈ 1.18 MHz. One CPU cycle = 3 color clocks; one scanline = 76 CPU cycles. |
| Standard NMOS 6502 die otherwise | Decimal mode **works**; undocumented ("illegal") opcodes **work** — they are advanced material, not a beginner tool. |

## Registers

| Register | Size | Role |
| --- | --- | --- |
| `A` | 8 | Accumulator — all arithmetic and logic flows through it |
| `X` | 8 | Index register — counting, table indexing, `,X` addressing |
| `Y` | 8 | Index register — same uses, different addressing modes |
| `SP` | 8 | Stack pointer; stack is page `$01` (which mirrors the 128 bytes of RAM) |
| `PC` | 16 | Program counter — 12 bits effectively used on the 2600 |
| `P` | 8 | Status flags: `NV‑BDIZC` |

## Flags

| Flag | Name | Set when… | Cleared when… |
| --- | --- | --- | --- |
| `N` | Negative | bit 7 of the result is 1 | bit 7 is 0 |
| `V` | Overflow | signed add/sub crosses the −128..127 range | otherwise |
| `B` | Break | set by `PHP`/`BRK` to mark a stack copy | — (not a real register bit) |
| `D` | Decimal | `SED` (BCD mode for `ADC`/`SBC`) | `CLD` — **startup code should `CLD`** because power-on state is undefined on real hardware |
| `I` | Interrupt mask | `SEI` | `CLI` — irrelevant on the 2600 (no interrupts) |
| `Z` | Zero | the result is exactly 0 | otherwise |
| `C` | Carry | add/sift carried out, or compare had no borrow | otherwise |

Rules of thumb that answer 90% of questions:

- **`CMP`/`CPX`/`CPY` are subtractions that set flags and throw away the result.**
  `A ≥ M` → carry set; `A = M` → zero set.
- **`BEQ` tests `Z`, `BCC/BCS` test `C`, `BMI/BPL` test `N`, `BVS/BVC` test `V`.**
- The **overflow flag is for signed math only**; unsigned code branches on carry.

## Addressing modes

| Mode | Syntax (ACME) | Example | Notes |
| --- | --- | --- | --- |
| Implied | — | `INX` | operand implied by the instruction |
| Accumulator | `A` | `ASL A` | shifts rotate through the carry |
| Immediate | `#value` | `LDA #$42` | literal; missing `#` means memory |
| Zero page | `$nn` | `LDA $80` | 1-byte address; **all 2600 RAM is zero page** |
| Zero page,X / ,Y | `$nn,X` | `LDA $80,X` | wraps **within** `$00–$FF` (a real hazard near `$FF`) |
| Absolute | `$nnnn` | `LDA $F000` | 2-byte address |
| Absolute,X / ,Y | `$nnnn,X` | `LDA data,X` | +1 cycle when the index crosses a page |
| Indirect | `(addr)` | `JMP ($FFFC)` | `JMP` only; NMOS bug: if low byte is `$FF` it reads the high byte from the same page |
| Indexed indirect | `(zp,X)` | `LDA ($80,X)` | pointer table lookup |
| Indirect indexed | `(zp),Y` | `LDA ($80),Y` | pointer in zero page, Y added; +1 cycle on page cross |
| Relative | branch target | `BNE loop` | ±127 bytes from the *next* instruction |

## Instruction & cycle table (NMOS 6502)

Cycles are for the base case; `+` marks "**+1 if a page boundary is crossed**". On the
2600, a wrong cycle count in the kernel shows up as a torn or rolled picture — count them.

| `ADC` / `SBC` / `AND` / `ORA` / `EOR` | `#`2 · zp 3 · zp,X 4 · abs 4 · abs,X 4+ · abs,Y 4+ · (zp,X) 6 · (zp),Y 5+ |
| `LDA` | `#`2 · zp 3 · zp,X 4 · abs 4 · abs,X 4+ · abs,Y 4+ · (zp,X) 6 · (zp),Y 5+ |
| `LDX` | `#`2 · zp 3 · zp,Y 4 · abs 4 · abs,Y 4+ |
| `LDY` | `#`2 · zp 3 · zp,X 4 · abs 4 · abs,X 4+ |
| `STA` | zp 3 · zp,X 4 · abs 4 · abs,X 5 · abs,Y 5 · (zp,X) 6 · (zp),Y 6 |
| `STX` | zp 3 · zp,Y 4 · abs 4 |
| `STY` | zp 3 · zp,X 4 · abs 4 |
| `CMP` | `#`2 · zp 3 · zp,X 4 · abs 4 · abs,X 4+ · abs,Y 4+ · (zp,X) 6 · (zp),Y 5+ |
| `CPX` / `CPY` | `#`2 · zp 3 · abs 4 |
| `INC` / `DEC` | zp 5 · zp,X 6 · abs 6 · abs,X 7 |
| `INX` / `INY` / `DEX` / `DEY` | 2 |

Undocumented opcodes (e.g. `LAX`, `SAX`, `DCP`, `SLO`) exist on this die and are covered in
the advanced part of the course. Do not use them unless a lesson explicitly teaches them.

## The stack

- Lives in page `$01`; on the 2600 that page **mirrors the 128-byte RAM** (`$80–$FF`), so a
  deep call chain or many pushes will silently overwrite game variables.
- `JSR` pushes address−1 and `RTS` adds 1; `PHA`/`PLA` move single bytes; `PHP`/`PLP` save
  flags. Keep subroutines shallow and balanced.

## Multiplication and division

The 6502 has no multiply or divide. Standard idioms:

- **× 2ⁿ** — repeated `ASL` (for `A`) or arithmetic on a scratch byte pair.
- **General 8×8** — shift-and-add loop (add multiplicand when multiplier bit is set, shift).
- **÷ 2ⁿ** — repeated `LSR`.
- Small courses use **lookup tables** instead of runtime math (lesson on lookup tables).

## ACME syntax used by this project

| Construct | Meaning |
| --- | --- |
| `!cpu 6502` | select the CPU (affects available opcodes) |
| `!source "include/vcs.asm"` | include another source file |
| `* = $F000` | set the program counter / origin |
| `!byte` `!word` | emit bytes/16-bit little-endian words |
| `!fill n, value` | emit `n` copies of `value` (ROM padding) |
| `Label:` | global label |
| `.local` | local label, scoped under the previous global label |
| `-`, `+`, `--`, `++` | anonymous labels; `BNE -` means "branch back to the previous `-`" — ideal for short loops |
| `!macro name { … }` + `+name` | define and invoke a macro; parameters are `.param` and referenced as `.param` inside |
| `!if` / `!else` / `!endif` | assembly-time conditionals |

The course's own `include/macro.asm` demonstrates every one of these idioms.
