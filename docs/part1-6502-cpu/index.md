## What You'll Learn

Part 1 re-introduces the processor that powered the golden age of gaming:

- **Lesson 04** meets the A, X, and Y registers and the load/store instructions that move bytes between them and memory
- **Lesson 05** puts the accumulator to work with addition, subtraction, and the carry flag
- **Lesson 06** explores the status flags and comparison instructions that let the CPU make decisions
- **Lesson 07** turns those flags into branches and loops — real control flow
- **Lessons 08–11** cover the stack and subroutines, bitwise operations, every addressing mode, and lookup tables

By the end of Part 1 you'll be writing real 6502 code and be ready to tackle the TIA and the television in Part 2.
