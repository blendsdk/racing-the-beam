**Why the Part 6 evidence is structured this way (AR #6, #28).** A game's logic is temporal: a
collision, a score carry, a state transition, or an LFSR step is a value at a frame. The state log
proves the value and the frame; the static ledger proves the cycle and frame arithmetic; the
screenshot proves the monitor state the reader sees. A screenshot never proves the logic, and the
lesson documents say so. This is the Part 2–5 method carried forward.
