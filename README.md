# Atari 2600 Development Starter

A minimal, well-commented Atari 2600 project template using the **ACME assembler** and **Stella emulator**.

## Quick Start

```bash
# Build the ROM
make

# Build and run in Stella
make run

# Clean build artifacts
make clean
```

## Project Structure

```
2600/
├── include/
│   ├── vcs.asm        # Hardware register definitions (TIA + RIOT)
│   └── macro.asm      # Helper macros (clean_start, vsync, timers)
├── src/
│   └── main.asm       # Your program — rainbow background demo
├── build/
│   └── game.bin       # Compiled ROM (4KB, generated by make)
├── Makefile           # Build commands
└── README.md          # This file
```

## What the Starter ROM Does

Displays a **rainbow gradient** that shifts colors every frame. It demonstrates the complete Atari 2600 frame structure:

```
262 scanlines per NTSC frame (60 fps):
  ┌─ VSYNC    (3 lines)   — signal new frame to TV
  ├─ VBLANK   (37 lines)  — screen blanked; game logic here
  ├─ KERNEL   (192 lines) — visible picture; draw here
  └─ OVERSCAN (30 lines)  — screen blanked; more logic time
```

## The Atari 2600 Hardware

| Chip | Role | Key Detail |
|------|------|------------|
| **6507** (CPU) | Runs your code | 6502 variant, 1.19 MHz, 13 address lines |
| **TIA** | Graphics & sound | No frame buffer! You "race the beam" |
| **RIOT** (6532) | RAM + I/O + Timer | 128 bytes RAM, joystick/switches, countdown timer |

## Prerequisites

- **ACME assembler** — `sudo apt install acme` or from [GitHub](https://github.com/meonwax/acme)
- **Stella emulator** — `sudo apt install stella` or from [stella-emu.github.io](https://stella-emu.github.io/)

## Stella Tips

| Key | Action |
|-----|--------|
| `Tab` | Toggle properties dialog |
| `\`` (backtick) | Open debugger |
| `Ctrl+R` | Reload ROM |
| `F1` | Toggle TV format (NTSC/PAL) |
| Arrow keys | Joystick directions |
| `Space` | Fire button |
| `F2` | Console Reset |
| `F3` | Console Select |

## Next Steps

Once you have the rainbow working, try these exercises:

1. **Read the joystick** — Check `SWCHA` and change the color based on direction
2. **Draw a playfield** — Set `PF0`, `PF1`, `PF2` to create walls/barriers
3. **Add a player sprite** — Load a bitmap into `GRP0` and position with `RESP0` + `HMP0`
4. **Make it move** — Update sprite position based on joystick input each frame
5. **Add collision detection** — Read `CXP0FB` to detect sprite-playfield collisions
6. **Add sound** — Set `AUDC0`, `AUDF0`, `AUDV0` for simple tones
